## Huffman Encryption/Decryption Lab

This project implements Huffman coding, a lossless data compression algorithm.
It can:

* Encode a text file into a compressed binary format using Huffman codes.

* Decode the compressed file back to its original text.

* The program demonstrates key concepts in:

* Frequency analysis of characters.

* Construction of a Huffman tree.

* Generation of variable-length prefix codes.

* File I/O for encoding/decoding.

Huffman coding is widely used in compression formats like JPEG and MP3. This project serves as both an educational lab and a working example of how the algorithm operates.
